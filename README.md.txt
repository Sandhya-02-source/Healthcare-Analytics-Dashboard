# Healthcare Analytics Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze healthcare data, including patient demographics, medical conditions, healthcare costs, insurance claims, patient outcomes, and readmissions.

## Objectives
- Analyze patient demographics and medical conditions.
- Monitor healthcare costs and insurance claims.
- Understand patient outcomes and readmission patterns.
- Present key performance indicators using interactive dashboards.

## Tools and Technologies
- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Key Features
- Interactive KPI cards and charts.
- Patient demographics and condition analysis.
- Financial and insurance analysis.
- Recovery and readmission analysis.
- Interactive slicers and page navigation.
- Drill-down, drill-through, and report-page tooltips.
- Decomposition Tree, Key Influencers, and Smart Narrative.

## Learning Outcomes
- Data cleaning and transformation.
- Creating DAX measures and calculated columns.
- Building interactive dashboards.
- Analyzing data to identify patterns and trends.

## Disclaimer
This project is for educational and portfolio purposes.
